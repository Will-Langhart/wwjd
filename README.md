# WWJD E-Commerce Store

A modern, full-stack e-commerce application built with React, TypeScript, and Lovable Cloud. This store features Shopify integration, user authentication, wishlist functionality, and email notifications.

## 🚀 Features

- **Shopify Integration**: Product catalog, cart management, and checkout
- **User Authentication**: Secure signup/login with Supabase Auth
- **User Profiles**: Manage account details, shipping addresses, and order history
- **Wishlist**: Save favorite products with email notifications
- **Email Notifications**: Welcome emails, order confirmations, and wishlist updates via Resend
- **Responsive Design**: Mobile-first design with Tailwind CSS
- **Secure Backend**: Row-Level Security (RLS) policies and input validation

## 🛠️ Tech Stack

### Frontend
- **React 18** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first styling
- **shadcn/ui** - UI component library
- **TanStack Query** - Data fetching and caching
- **Zustand** - State management (cart)
- **React Router** - Client-side routing

### Backend (Lovable Cloud)
- **Supabase** - PostgreSQL database, authentication, and edge functions
- **Row-Level Security** - Database-level access control
- **Edge Functions** - Serverless backend logic
- **Resend API** - Email delivery service

## 📦 Installation

### Prerequisites
- Node.js 16+ and npm
- A Lovable account (for backend services)
- Shopify store credentials
- Resend API key (for email notifications)

### Setup

1. **Clone the repository**
```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
```

2. **Install dependencies**
```sh
npm install
```

3. **Configure environment variables**

The `.env` file is auto-generated by Lovable Cloud and includes:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
- `VITE_SUPABASE_PROJECT_ID`

4. **Configure Shopify**

Update `src/lib/shopify.ts` with your Shopify store credentials:
```typescript
const SHOPIFY_STORE_DOMAIN = 'your-store.myshopify.com';
const SHOPIFY_STOREFRONT_ACCESS_TOKEN = 'your-token';
```

5. **Configure Resend (Email Service)**

Add your Resend API key as a secret:
- Go to [resend.com](https://resend.com) and create an account
- Generate an API key at [resend.com/api-keys](https://resend.com/api-keys)
- Verify your sending domain at [resend.com/domains](https://resend.com/domains)
- Add the secret in Lovable Cloud settings

6. **Start the development server**
```sh
npm run dev
```

The app will be available at `http://localhost:8080`

## 🔐 Security

This application implements multiple security layers:

- **Row-Level Security (RLS)**: All database tables use RLS policies to ensure users can only access their own data
- **JWT Authentication**: Edge functions verify user identity via JWT tokens
- **Input Validation**: Zod schemas validate all user inputs
- **HTML Sanitization**: Email templates escape user-provided content to prevent XSS
- **Rate Limiting**: Protected endpoints prevent abuse

## 📧 Email Notifications

The app sends automated emails for:
- **Welcome emails** on signup
- **Order confirmations** after purchase
- **Wishlist updates** when items are added

Email templates use the Resend API and include proper authentication and validation.

## 🚢 Deployment

### Deploy to Production

1. Open your [Lovable Project](https://lovable.dev/projects/c9dab636-c75f-455c-860d-778993376eb3)
2. Click **Publish** (top right on desktop, bottom right on mobile)
3. Click **Update** to deploy frontend changes

**Note**: Backend changes (edge functions, database migrations) deploy automatically.

### Custom Domain

Connect a custom domain in Project > Settings > Domains. See [Lovable Docs](https://docs.lovable.dev/features/custom-domain) for details.
